# Satyam Gupta — Portfolio Website

A professional portfolio website showcasing all my public projects, tools and apps.

**Live preview:** open `index.html` in a browser, or deploy to GitHub Pages / Vercel / Netlify.

## What's inside

- **Hero section** with animated stats and live GitHub data
- **41 projects** — web tools, Android apps, TypeScript projects and more
- **Filter + search** — browse by category (Web Tools, Android Apps, TypeScript, Other)
- **About & contact** sections
- Fully responsive, dark professional theme

## Deploy

### GitHub Pages
1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch** → `main` → `/ (root)`
3. Your site goes live at `https://<username>.github.io/portfolio/`

### Vercel / Netlify
Just import this repo — no build step needed (pure HTML/CSS/JS).

## Structure

```
├── index.html
├── css/style.css
├── js/main.js   ← edit project list here
└── README.md
```

To update the project list, edit the `PROJECTS` array in `js/main.js`.
